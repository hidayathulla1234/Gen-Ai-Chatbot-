

# 🤖 GenAI Chatbot

A simple AI-powered chatbot built using Python, Streamlit, LangChain, and Groq API.

## 🚀 Live Demo

🌐 Live App: https://genaichatbot-01.streamlit.app/

---

# 📌 Features

* AI-powered chatbot
* Built with Streamlit UI
* Uses Groq LLM models
* Fast response generation
* Clean and simple interface
* Easy deployment on Streamlit Cloud

---

# 🛠️ Tech Stack

* Python
* Streamlit
* LangChain
* Groq API

# ⚙️ Installation

## Clone Repository

```bash
git clone https://github.com/your-username/gen-ai-chatbot.git
```

## Move to Project Folder

```bash
cd gen-ai-chatbot
```

## Install Dependencies

```bash
pip install -r requirements.txt
```

---

# 🔑 Environment Variables

Create a `.env` file:

```env
GROQ_API_KEY=your_api_key
```

---

# ▶️ Run Application

```bash
streamlit run chatbot.py
```

# ☁️ Deployment

This project is deployed using Streamlit Cloud.

## Deploy Steps

* Push project to GitHub
* Open Streamlit Cloud
* Connect GitHub repository
* Add GROQ_API_KEY in Streamlit Secrets
* Deploy application
